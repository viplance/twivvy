# Difficulty selector artwork

Three illustrations generated with the built-in imagegen tool on 19 October 2026, inspired by the menu's ink-and-watercolor hamster illustration. Each final asset is a 512 × 512 PNG with transparency, in `HamsterLab/Resources/Assets.xcassets/Difficulty{Easy,Medium,Hard}.imageset`. PNG preserves the transparent background; no text is embedded, so the selector uses the existing localized difficulty labels.

Validation: the iPhone 16 Pro Max / iOS 18.6 simulator UI test
`testIllustratedDifficultySelection` passed. It selects Hard via its illustration,
selects Easy via the segmented control, verifies both selections stay synchronized,
and starts training. Both selector screenshots were inspected.
